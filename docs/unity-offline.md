# Unity 嵌字翻译首版

入口为左侧「Unity 翻译」。先选择或拖入游戏目录 / 主程序并识别游戏，再选择「嵌字翻译」或「运行时翻译」；两种模式共用游戏列表、最近打开记录与当前游戏。

## 操作

1. 在 Unity 设置保存输出目录；默认使用软件目录下的 `unity-output`。大模型使用「设置 → 通用」当前选中的模型、API 地址与密钥，本机模型同样通过通用配置连接；翻译引擎使用通用中保存的引擎凭证及代理。
2. 识别并选择游戏后进入「嵌字翻译」，自动加载当前游戏的任务和保存工程：优先使用任务索引，没有索引时从当前输出目录查找该游戏最近保存的工程。没有历史工程时直接使用一键流程。处理游戏数据目录中的 UTF-8 TXT / JSON、Unity TextAsset 和序列化游戏组件；Mono 游戏可从 Managed 程序集读取结构定义，提取对白、选项、名称、描述和 UI 字段，即使资源未内嵌类型树。程序集中仅解析元数据，不执行游戏代码。可选扫描 Mono 代码字面量和版本 24–31 的标准 IL2CPP metadata 字面量。
3. 选择「大模型」或「翻译引擎」及语言，点击「一键生成并应用」，自动扫描、翻译、生成补丁并应用到当前游戏；已有工程时保留选取和译文，仅翻译未完成文本。也可逐步操作，取消「翻译完成后生成补丁」先供人工检查。「重新扫描」在确认后建立新工程，保留旧工程及原文与定位未变化条目的译文和选取；原文改变的条目需重新翻译。「更多 → 导入其他工程」用于手动关联迁移工程，日常无需重复打开工程。工程与进度不属于可随意清理的普通缓存。
4. 可选提供具有目标语言字形的 TTF / OTF。首版检测 Unicode cmap 缺字并替换已识别的 UGUI FontData，不生成 TMP / NGUI 图集。
5. 请先关闭游戏。补丁目录中 `patch` 保存修改文件，`original` 保存对应原件，`manifest.json` 记录哈希。一键流程最后自动应用，也可在生成后单独点击「应用到游戏」。应用前检查游戏进程、原文件及补丁哈希，逐文件原子替换并校验，写入失败时回滚；原件备份始终保留，可按相对路径复制回游戏恢复。

## 进度、中止与恢复

四个步骤均显示当前操作、已处理数量和本步进度，单条进度条平滑过渡，处理中有左到右的流光。列目录或校验时尚无准确总量，显示准备状态，不编造百分比；失败、中止及完成后停止流光。单独执行步骤和一键流程均可「中止」「恢复」，资源操作在当前文件安全处理完后停止。失败原因和处理建议直接显示，原始错误折叠在技术详情中。

每一阶段分别显示已完成、进行中或未开始，单独完成扫描不表示后续步骤已完成。未知总量时填充从 0 开始，只有流光表示正在处理。说明、授权、制作名单、引擎构建信息和运行时标识不作为游戏原文；旧提取方式建立的工程会提示重新扫描，一键流程自动重新提取并保留未变化条目的译文。

- 扫描按文件保存工程和扫描位置；恢复继续剩余文件。翻译逐条保存，恢复跳过有效译文，不重复请求已完成文本。
- 补丁生成保存已完成文件和原件备份，恢复校验后继续，不重复生成已完成文件；译文或字体改变时不能混用旧检查点。
- 应用记录完成文件并校验哈希，恢复跳过已写入文件；中止或意外退出可能留下部分已应用文件，应用完成前请勿启动游戏。写入失败会尝试回滚，若回滚失败会列出需从 `original` 恢复的文件。
- 重新选择当前游戏时读取本机保存的任务索引，加载工程并显示恢复入口，不自动继续联网翻译或写入游戏。任务索引不保存密钥，检查点和工程保存在输出目录。处理中退出会先中止并保存，再关闭窗口。
- 「结束本次流程」保留工程、译文和补丁，但不再自动继续；应用中止后必须恢复完成，不能直接结束以免误把部分应用当作完成。支持范围和实际游戏显示限制不因一键操作而改变。

## 运行时模型与引擎

运行时可使用插件自带引擎，也可点击「使用 LLMChat 大模型翻译」启用已有 CustomTranslate 本地桥接。桥接直接读取通用的当前模型、API 和密钥，游戏配置只写入本地桥接地址，不写入大模型密钥；使用期间需保持 LLMChat 运行。

插件自带引擎的参数写入 AutoTranslator 自己的 Config.ini，与通用翻译引擎接口不是同一条调用链，因此仍在 Unity 设置中维护。嵌字模式不安装运行时插件。

## 已实现的检查与限制

- 校验占位符、转义和富文本标签集合，空译文或缺字阻止生成。检查源文件哈希，源文件变化时要求重新扫描。
- JSON 保留键和结构，不翻译明确的标识、路径等字段；TXT 保持换行。自定义二进制、CSV / XML、图片文字、加密资源不自动解析。
- 字面量中可能包含影响程序运行的标识，因此代码扫描默认关闭；启用后必须检查选取结果。已签名 Mono 程序集不自动回写。
- 支持序列化 assets 以及可读取的 Unity Bundle 回写。修改 Bundle 不自动更新 Addressables Catalog / CRC，不保证游戏允许加载；扫描提示会列出已检测的 Catalog。
- 缺少 Managed 程序集或结构解析失败的自定义组件会显示跳过原因。TMP / NGUI 字体图集、特殊 shader、运行时动态生成文本仍不能自动处理；TMP 的序列化文字可提取，但这不等于支持其中文字库替换。类型数据库覆盖不到的引擎版本会显示错误。
- 补丁生成失败时保留 `INCOMPLETE.txt`，不得使用此目录。游戏加载、排版和字体实际显示仍需用目标游戏验证。
- 翻译通过用户选择的已有模型连接发送；工程与补丁不保存密钥。使用本机模型时不需要将原文发给云端服务。

## 构建

需要 .NET SDK 8 或更新版本。`scripts/prepare-unity-tools.ps1` 发布 Windows x64 自包含组件并下载固定版本、校验 SHA-256 的类型数据库；最终用户无需安装 .NET。

Tauri 的构建前命令自动准备组件，便携打包复制 `resources/unity`。开发时先按仓库全局锁流程运行准备脚本，再启动 Tauri。NuGet 与类型数据库首次下载需要网络；组件准备好以后，扫描和生成补丁不联网。

核心依赖为 AssetsTools.NET 3.0.5、Mono.Cecil 0.11.6；类型数据库来自固定 UABEA 提交。第三方说明随组件放在 `resources/unity`，不分发教程工具包中的旧 EXE 或“特别版”程序。
