# Unity 嵌字翻译首版

入口为左侧「Unity 翻译」。选择或拖入游戏目录 / 主程序并识别游戏后默认进入嵌字翻译，上方可切换运行时翻译，无需额外选择模式页面。游戏标题、模式和一键操作合并在同一栏。

目录检测由本地服务的后台请求线程执行，不锁定最近打开列表。点击最近游戏会取消当前扫描并仅检查该游戏目录；客户端断开后，递归扫描在下一检查点结束，旧结果不再覆盖新选择。不点击时继续检测至完成。启动时读取上次游戏工作目录的任务摘要，未完成的工程自动打开并恢复原步骤，不自动开始翻译或应用；已经开始手动选择时不抢走当前界面。

## 操作

1. 工程、检查点、中间文件、补丁和原件备份统一保存在游戏内的 `LLMChat-Unity` 工作文件夹。任务索引存为工作目录的 `task-state.json`，工作文件路径相对于此文件夹保存。读取进度直接使用游戏工作目录，不依赖软件目录或浏览器缓存。已有软件目录工程在首次进入时复制迁移，旧文件保留；不再提供手动导入入口。游戏目录必须可写，不静默改存到软件目录。
2. 识别并选择游戏后，自动加载对应游戏工作目录中的任务和工程，没有历史工程时使用一键流程。扫描排除 `LLMChat-Unity`，防止重复提取自己的工程和备份。处理游戏数据目录中的 UTF-8 TXT / JSON、Unity TextAsset 和序列化游戏组件；Mono 游戏可从 Managed 程序集读取结构定义，提取对白、选项、名称、描述和 UI 字段，即使资源未内嵌类型树。程序集中仅解析元数据，不执行游戏代码。可选扫描 Mono 代码字面量和版本 24–31 的标准 IL2CPP metadata 字面量。
3. 点击四个步骤标题切换参数：扫描步骤配置原文范围和代码扫描；翻译步骤配置大模型／翻译引擎及目标语言；补丁步骤配置可选字体并显示工作目录；应用步骤显示写入位置和检查要求。各单步按钮仅执行本步，缺少前一步结果时禁用；可提前配置后续步骤。一键处理依次使用全部参数。重新扫描建立新工程并保留旧工程和匹配译文。步骤区与结果区之间，以及表格来源、原文与译文列之间均可拖动分隔线调整宽度；窄窗口自动上下排列。
4. 可选提供具有目标语言字形的 TTF / OTF。首版检测 Unicode cmap 缺字并替换已识别的 UGUI FontData，不生成 TMP / NGUI 图集。
5. 请先关闭游戏。补丁目录中 `patch` 保存修改文件，`original` 保存对应原件，`manifest.json` 记录哈希。一键流程最后自动应用，也可在生成后单独点击「应用到游戏」。应用前检查游戏进程、原文件及补丁哈希，逐文件原子替换并校验，写入失败时回滚；原件备份始终保留，可按相对路径复制回游戏恢复。

## 进度、中止与恢复

四个步骤均显示当前操作、已处理数量和本步进度，单条进度条平滑过渡，处理中有左到右的流光。列目录或校验时尚无准确总量，显示准备状态，不编造百分比；失败、中止及完成后停止流光。单独执行步骤和一键流程均可「中止」「恢复」，资源操作在当前文件安全处理完后停止。失败原因和处理建议直接显示，原始错误折叠在技术详情中。

步骤标题不重复显示状态文字：完成步骤淡绿、当前步骤淡蓝、尚未执行步骤淡橙，选中参数页显示对应的深色；查看参数不改变任务进度。未知总量时填充从 0 开始，只有流光表示正在处理。说明、授权、制作名单、引擎构建信息和运行时标识不作为游戏原文；旧提取方式建立的工程会提示重新扫描，一键流程自动重新提取并保留匹配译文。

翻译前用第一条实际待翻译文本检查服务可用性，成功结果直接保存复用，不额外发送重复测试文本。预检失败不启动批量；处理中连续 3 次或累计 5 次请求失败，保存已完成译文后自动停止并显示原因。文件保存失败立即停止，不将其当作服务请求失败继续处理。列表错误收为紧凑详情入口，不再把每行撑高。

大模型翻译可跟随通用当前模型，也可在翻译步骤选择通用中已配置的其他模型，包括本地模型。连接地址和凭证仍从通用读取，不写入游戏工程；任务仅保存所选模型标识。本机模型服务须先启动，可不填 Key。查看后续步骤时显示该步参数，不显示其他步骤的进度条；正在执行的任务另有紧凑的中止、恢复和查看进度入口。每步成功完成后切到下一步参数页，最后一步留在本页；单步操作只切页，不自动启动下一步。重做按钮以黄色显示，清理完成后仍由用户手动启动。

同一原文在本轮只请求一次，包括失败条目；换行格式、Unicode 组合形式和首尾空白归一后去重，原资源位置与首尾空白保留，译文传播到所有待处理引用。已有有效人工译文保留并可复用。进度同时显示条目数量和去重后的原文种类。

翻译步骤的“换行处理”默认合并段内单次换行，再将整条文本发送给引擎或模型；中日文相邻文字直接连接，其他文字间保留空格，空行和程序转义保持不变。原文不改写，译文不强制恢复原行数；需要固定行布局或逐行列表时可选择“保留换行”。大模型结合整条内容理解上下文。选项随任务保存，恢复使用原选项；已有译文不会自动覆盖，需要重新翻译时可重做翻译步骤。

翻译主进度按已完成的唯一原文种类计算，另列资源位置覆盖数、本轮请求数和复用种类；重复文本不会把一次请求伪装成大量独立翻译。结果分页可跳转指定页，或前后移动十页。

类型、程序集、方法及 Unity 事件绑定标识不属于游戏文字。扫描时排除，旧工程载入和保存时剔除误收条目，保留正常译文和资源位置；生成补丁再次检查，旧规则生成且缺少保护校验的补丁禁止应用，须重新生成。保留原件备份用于恢复已应用的旧补丁，不把错误的类型标识译文写回游戏。

翻译中止后可继续，或选择“跳过剩余并生成补丁”，仅回写已完成且校验有效的所选译文，其余保持原文；这个选择随检查点保存，不自动应用游戏。完成步骤可“重做此步”：先校验并恢复已应用的游戏原件，再清除本步及后续产物，随后调整参数重新开始。重做应用也会删除旧补丁，需要重新生成。清理过程有独立检查点，异常中断后打开游戏工作目录会先完成已授权的清理；游戏文件被其他程序修改时停止并保留备份。

步骤失败显示淡红，选中为红色；查看其他参数页时，正在执行的步骤用呼吸效果强调。步骤区与输出区可拖动调整高度，输出区填满剩余空间，工作目录位于顶端。读取到对象数据末尾的提示按类别汇总，显示受影响对象及未提取文本/字体的影响，不能仅凭这类提示认定游戏损坏。

## 多语言文本范围

游戏资源可能同时保存日文、英文、韩文等字符串。工程保留完整提取结果；默认按数量最多的主语言显示，原文语言可手动指定或选择「全部语言」。列表、翻译选取、补丁回写和字体缺字检查均使用同一语言范围，不会把未翻译的其他语言混入补丁。未带语言标签的文本按文字特征判断，纯汉字可能同时用于中文和日文，因此不强制删除。切换语言不会删除原文、译文或手动选取。

- 扫描按文件保存工程和扫描位置；恢复继续剩余文件。翻译逐条保存，恢复跳过有效译文，不重复请求已完成文本。
- 补丁生成保存已完成文件和原件备份，恢复校验后继续，不重复生成已完成文件；译文或字体改变时不能混用旧检查点。
- 应用记录完成文件并校验哈希，恢复跳过已写入文件；中止或意外退出可能留下部分已应用文件，应用完成前请勿启动游戏。写入失败会尝试回滚，若回滚失败会列出需从 `original` 恢复的文件。
- 重新选择当前游戏时读取本机保存的任务索引，加载工程并显示恢复入口，不自动继续联网翻译或写入游戏。任务索引不保存密钥，检查点和工程保存在输出目录。处理中退出会先中止并保存，再关闭窗口。
- 「结束本次流程」保留工程、译文和补丁，但不再自动继续；应用中止后必须恢复完成，不能直接结束以免误把部分应用当作完成。支持范围和实际游戏显示限制不因一键操作而改变。

## 运行时模型与引擎

运行时可使用插件自带引擎，也可点击「使用 LLMChat 大模型翻译」启用已有 CustomTranslate 本地桥接。桥接直接读取通用的当前模型、API 和密钥，游戏配置只写入本地桥接地址，不写入大模型密钥；使用期间需保持 LLMChat 运行。

插件自带引擎的参数写入 AutoTranslator 自己的 Config.ini，与通用翻译引擎接口不是同一条调用链，因此仍在 Unity 设置中维护。嵌字模式不安装运行时插件。

## 已实现的检查与限制

- 校验占位符、转义和富文本标签集合，空译文或缺字阻止生成。检查源文件哈希，源文件变化时要求重新扫描。
- JSON 保留键和结构，不翻译明确的标识、路径等字段；TXT 保持换行。自定义二进制、CSV / XML、图片文字、加密资源不自动解析。
- 字面量中可能包含影响程序运行的标识，因此代码扫描默认关闭；启用后必须检查选取结果。已签名 Mono 程序集不自动回写。
- 支持序列化 assets 以及可读取的 Unity Bundle 回写。修改 Bundle 不自动更新 Addressables Catalog / CRC，不保证游戏允许加载；扫描提示会列出已检测的 Catalog。
- 缺少 Managed 程序集或结构解析失败的自定义组件会显示跳过原因。TMP / NGUI 字体图集、特殊 shader、运行时动态生成文本仍不能自动处理；TMP 的序列化文字可提取，但这不等于支持其中文字库替换。类型数据库覆盖不到的引擎版本会显示错误。
- 补丁生成失败时保留 `INCOMPLETE.txt`，不得使用此目录。游戏加载、排版和字体实际显示仍需用目标游戏验证。
- 翻译通过用户选择的已有模型连接发送；工程与补丁不保存密钥。使用本机模型时不需要将原文发给云端服务。

## 构建

需要 .NET SDK 8 或更新版本。`scripts/prepare-unity-tools.ps1` 发布 Windows x64 自包含组件并下载固定版本、校验 SHA-256 的类型数据库；最终用户无需安装 .NET。

Tauri 的构建前命令自动准备组件，便携打包复制 `resources/unity`。开发时先按仓库全局锁流程运行准备脚本，再启动 Tauri。NuGet 与类型数据库首次下载需要网络；组件准备好以后，扫描和生成补丁不联网。

核心依赖为 AssetsTools.NET 3.0.5、Mono.Cecil 0.11.6；类型数据库来自固定 UABEA 提交。第三方说明随组件放在 `resources/unity`，不分发教程工具包中的旧 EXE 或“特别版”程序。
