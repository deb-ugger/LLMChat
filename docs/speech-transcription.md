# 语音转文字

## 在线识别与大模型校对

操作页选择“本地识别”或“在线识别”，并可独立开启“大模型校对”。在线识别支持 Gemini、通义 Omni 和支持 Chat Completions 音频输入的自定义接口。预填模型分别为 `gemini-3.8-flash` 与 `qwen3.8-omni-flash`；模型 ID 可修改。旧版仅支持流式返回的 Omni 型号不能用于此非流式接口。

在“设置 → 语音转文字 → 在线识别接口”配置 URL 和 Key，或沿用“通用”中对应厂商的凭证。自定义接口的音频字段使用原始 WAV Base64；通义使用 WAV Data URI。校对模型在操作页选择，凭证沿用“通用”配置，也可使用无需 Key 的本地兼容文本服务。网络代理沿用全局配置。

在线识别只发送当前最多 30 秒的 16 kHz 单声道 WAV，不上传整份长录音。结果必须包含有效、按序且位于片段内的字幕时间戳；时间戳由模型估计。校对仅发送字幕编号和文字，不发送音频；校对返回条目数量及编号必须一致，仅替换文字，时间轴保持不变。字幕内的内容按数据处理，不作为提示词指令。在线服务和校对可能产生费用，音频或字幕会发送至所选接口。

每段识别、校对及简繁转换成功后才提交断点并写入字幕；出错停止并显示原因，不静默写入未经校对的结果。暂停/取消会终止前端请求并通知后端取消供应商请求。尚未提交的片段在继续时重做。任务元数据保留识别方式、模型和校对选项，不写入 API Key；继续任务时重新读取凭证。在线请求用量分别记为“在线语音识别”和“字幕校对”。

定向验证：`frontend/scripts/test-speech-online.mts`、`test-speech-queue.mts`；`backend/tests/speech` 使用本机模拟供应商验证真实 WinHTTP、请求格式、用量解析和在途取消，不调用付费服务。

接口依据：[Gemini 音频输入](https://ai.google.dev/gemini-api/docs/openai)、[通义 Omni](https://help.aliyun.com/en/model-studio/qwen-omni)。

## 操作与队列

在“语音转文字”页点击添加文件，或将多个本地音频拖入窗口。文件加入队列后可单独开始、暂停、继续或取消，也可以开始/继续整个队列及全部暂停。设置中的“最多同时处理文件数”控制推理并发（1–4，默认 1）。本地模型每个并发任务各占一份运行内存，大模型建议保持并发 1。

左侧队列与设置之间、左右区域之间均可拖动调整尺寸，尺寸在本机保存。试听播放器的音量滑块为竖向显示。模型名称不包含下载状态，状态单独展示。

输出位置显示在右侧结果区。任务暂停后可点击“清除进度”，删除该任务生成的字幕和断点，保留原音频及用户额外放入的文件；任务回到等待开始，下一次开始采用当前模型、录音语言和输出设置。

## 文件、断点和输出

开始时为每个文件建立独立的 `原音频名_YYYY-MM-DD` 目录，日期使用任务创建时的本地日期。SRT、VTT、TXT 可以多选，文件名与目录同名，例如 `会议录音_2026-10-22.txt`。同一天重复处理同一音频时，目录和文件名依次追加 `（2）`、`（3）`；并行创建也不会覆盖已有结果。格式、模型、语言和中文字形保存在任务内，暂停及恢复沿用原文件名。旧任务继续使用其原目录和文件名。原音频始终只读。

音频使用随软件分发的 FFmpeg 按 30 秒窗口读取为 16 kHz 单声道，不再有前端的 200 MiB / 60 分钟硬限制。每段完成后先向 `progress.jsonl` 提交断点，再向输出文件追加文字。非末段优先在完整字幕句子处提交，未完成的尾部在下一窗口重读；不需要从整份音频开头重做。

暂停保留已提交的断点和输出，当前尚未提交的窗口可能在继续时重新识别。正在写入的窗口保存结束后才完成暂停。取消等待正在进行的写入结束，只删除该任务生成的输出、进度与元信息；不删除原音频或任务目录中用户额外放入的文件。

累计已用时保存在任务元信息中，每段提交及暂停、出错、完成时写回；恢复沿用累计值，不计入软件关闭或任务暂停的时间。只有明确清除进度建立新任务时归零。旧任务此前未记录的用时无法精确补回，从更新后的处理开始累计。

默认输出位置为软件目录下的 `speech-output`，手动选择的目录保留。旧版 AppData 默认目录里的任务仍会自动载入，不移动原文件。重新打开软件时，会从当前输出目录恢复任务。中途退出或断电后，继续任务会校验原文件大小与修改时间、舍弃不完整的最后一条进度，并从已提交记录重建输出，修复多文件写入中断。原音频发生改变时需重新添加。更换输出目录不会自动迁移旧任务；选择旧目录可重新发现其中的断点。

“在页面显示转写结果”可关闭。关闭后仍会写入文件，但不从磁盘读取整份转写用于展示。预览每页 100 段；纯文本预览和复制仅针对当前页，完整内容在输出文件中。

## 模型和中文

保留多语言 Whisper Tiny / Base / Small，并提供中文微调 Whisper Small、英文专用 Distil-Whisper Small.en、日语特化 Kotoba-Whisper v2.2。特化模型固定其对应语言；英文专用模型不传入多语言生成参数。日语特化 Q8 权重下载约 1 GiB，资源消耗明显更高。

“录音语言”指定音频中的语言，用于识别，不是翻译目标语言。“中文简繁转换”默认转为简体，也可转为繁体或不转换。识别语言为中文（包括自动检测到中文）时使用本地 OpenCC 转换；日文等语言不做汉字字形替换。

模型首次使用从 Hugging Face 下载并缓存在 WebView 的 `transformers-cache` 中；音频不上传。缓存状态根据实际模型文件显示，支持下载、继续下载和卸载。任务结束或暂停后自动关闭对应 Worker 以释放运行内存，下载缓存保留，不再需要手动点击“释放模型内存”。

## 构建与验证

申请全局构建锁后运行 `scripts/prepare-speech-tools.ps1`，准备 FFmpeg 9.0.2 的 Windows 工具和授权文件。下载使用 FFmpeg 官网列出的 Gyan 构建源并核对 SHA256；只提取 ffmpeg、ffprobe 及许可证说明。`make-portable.ps1` 将工具复制到便携版 `resources/ffmpeg`，保留用户数据。

定向验证：`frontend/scripts/test-speech-queue.mts` 检查并发、任务落盘时序、暂停/继续位置、取消清理和中文转换；`cargo test --lib speech::tests` 检查增量输出、破损末条恢复及超过 60 分钟音频的有界解码。模型识别效果受录音质量、口音、噪声影响，字幕需复核。
