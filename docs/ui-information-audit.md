# 界面信息重复检查

日期：2026-10-28。检查以同屏、同一语义及同一统计范围为准；不同范围、用途和操作风险的信息分别保留。本轮是主页面及相关可见区域的源码检查，不代表所有运行状态均已逐一进行人工截图验证。

| 模块 | 发现与处理 |
| --- | --- |
| Unity 嵌字翻译 | 删除扫描和翻译参数区重复的语言、范围和数量；标题只显示“文本与译文”，语言、总数、选中及可回写状态统一在结果工具栏显示一次。全选和全部可回写时用文字表达，不重复同一个总数。 |
| Unity 任务状态 | 当前步骤已有执行详情时，输出区不再复述同一状态。失败原因直接在错误面板解释，删除上下两处“失败请看输出”的指引。字体数量只保留在字体列表折叠标题，输出标题不再重复。 |
| Unity 游戏检测 | 无结果时只在空白结果区提示未找到游戏；扫描计数保留在结果标题旁，空白区不再重复扫描状态。 |
| 文本翻译工程 | 条目总数只保留在条目状态卡；Token 卡只显示 Token 数，百分比只保留在进度卡。运行中工具栏不再复述进度与成功/失败数量，运行结束的操作结果仍保留。 |
| 图片文字识别 | 工具栏和单页指标仅显示简短失败状态，具体错误只在对应错误区域完整展示。“识别到 N 段文字”状态改为“识别完成”，段数保留在专门指标中。累计指标与单页指标统计范围不同，保留。 |
| 语音转文字 | 搜索等待和未找到结果只在结果空白区显示一次；有命中时搜索框旁显示命中数量。音频队列总数、已完成/未完成数量和字幕段数统计范围不同，保留。 |
| 文献、图片、文本翻译设置 | 删除与已选模式卡、模型/引擎选择重复的“当前翻译方式”摘要；每个设置页的通用凭证位置说明保留一次，不在模式组内重复两遍。模型用途、下载状态、大小和实际限制保留。 |
| Unity 设置 | 删除与当前游戏/通用模板卡重复的顶部模板说明；凭证位置在断行说明中保留一次。 |
| 文献阅读与即时翻译 | 原文、译文、词典及 PDF/EPUB 的页码/检索信息职责不同，本轮未发现需要删除的同屏同口径统计。 |
| 对话 | 对话内容、操作反馈及模型选择职责不同，本轮未发现同屏重复的数据摘要。 |
| 用量统计 | 总体图表、分组明细、筛选结果和分页数量统计层级不同，保留。 |
| 存储及模型管理 | 总占用与分类占用、总清理计划与单项已安排状态各自服务操作；确认框中的删除影响是操作前确认信息，保留。 |

验证重点：全选、部分选择、未选、未扫描状态的结果统计；Token 与条目数不混用；OCR 完整错误保留；翻译流程、模型下载管理和数据清理行为不变。未为本次文案与显示条件变更执行真实 OCR、收费翻译请求或全量测试。
